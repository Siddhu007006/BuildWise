 
Construction Planning System 
AI-Powered Construction Project Planning with IBM Granite 3.3 
2B 
 
Project Description 
Construction Planning System is an intelligent project planning platform that leverages IBM's 
Granite 3.3 2B AI model (via Ollama) to provide comprehensive construction project analysis and 
planning recommendations. The platform addresses the challenge of accurate construction 
estimation by delivering AI-powered insights, detailed blueprints, resource allocation, cost 
analysis, and week-by-week construction schedules. 
Using Granite 3.3 2B's advanced language capabilities, the system analyzes project parameters 
(built-up area, number of floors, timeline constraints), generates accurate worker requirements, 
cost breakdowns, material estimations, and detailed architectural blueprints tailored to 
individual project specifications. The system ensures fast response times through local Ollama 
deployment while maintaining high-quality planning advice through sophisticated calculation 
algorithms and AI-powered analysis. 
Construction Planning System transforms project planning into an intelligent, user-friendly 
experience through its modern interface, comprehensive feature set, and AI-powered analysis 
that provides personalized construction guidance considering location-specific rates, building 
complexity, and realistic timelines. 
 
 
 
 
 
 
 
 
 
 
 
 

 
 
Scenarios 
Scenario 1:  
A contractor wants to plan a residential G+2 (3-floor) building of 1000 sq. yards. The system 
detects the project parameters, analyzes building complexity, and provides: 
●​ Worker requirements breakdown (masons, helpers, steel workers, carpenters, 
supervisors) 
●​ Total labour days calculation 
●​ Timeline estimation (days, weeks, months) 
●​ Detailed cost breakdown (labor, materials, overhead) 
●​ Material requirements (steel, cement, sand, water) 
●​ Professional architectural blueprint with room layouts and dimensions 
Scenario 2: Custom Timeline Planning 
A developer has budget constraints and wants to complete a 1500 sq. yard project in 90 days. 
The system: 
●​ Calculates required workforce for accelerated timeline 
●​ Adjusts material quantities based on faster execution 
●​ Provides cost implications of timeline compression 
●​ Generates optimized weekly construction schedule 
●​ Shows resource intensity requirements 
Scenario 3: Cost Analysis & Budget Planning 
A project manager needs to understand cost structure for a 2000 sq. yard, G+3 building. The 
system delivers: 
●​ Detailed cost breakdown (labor, materials, overhead) 
●​ Cost per sq. yard analysis 
●​ Material cost estimates with current rates 
●​ Labour cost projections 
●​ Overhead and contingency calculations 
●​ Customizable wage rates and material costs 
Scenario 4: Detailed Construction Schedule 
A contractor needs a comprehensive week-by-week plan including all finishing works. The 
system generates: 
●​ Foundation to handover timeline 
●​ All construction phases from site prep to final finishing 
●​ Electrical, plumbing, painting, and finishing schedules 
●​ Activity dependencies and durations 
●​ Resource allocation per phase 
 
 
 

 
 
Architecture Overview 
Construction Planning System is built as a modular platform combining Flask backend with 
IBM Granite 3.3 2B AI model for intelligent project planning. The architecture prioritizes 
accuracy, speed, and user experience by leveraging local AI inference and sophisticated 
calculation algorithms. 
Core Technologies 
●​ Flask: Lightweight Python web framework for routing and request processing 
●​ IBM Granite 3.3 2B: Local AI inference via Ollama for intelligent text generation 
●​ Ollama: Local LLM runtime for Granite model execution 
●​ Python Math & Algorithms: Construction calculation logic 
●​ HTML5/CSS3/JavaScript: Modern, responsive frontend with smooth animations 
●​ Real-time Visualization: Blueprint generation, timeline visualization 
●​ Local Deployment: No cloud API keys required 
 
Pre-requisites 
Software Requirements 
●​ Python 3.8+: Download from python.org 
●​ Ollama: Download from ollama.ai 
●​ Granite 3.3 2B Model: Pre-downloaded via Ollama (ollama pull 
granite:3.3-2b) 
●​ Git: Download from git-scm.com 
●​ Code Editor: VS Code, PyCharm, or any preferred IDE 
Knowledge Prerequisites 
●​ Python Basics: Functions, classes, OOP, exception handling 
●​ Flask Framework: Routing, request handling, JSON responses 
●​ HTML/CSS: Responsive design, Flexbox/Grid layouts 
●​ JavaScript: DOM manipulation, Fetch API, async/await 
●​ Construction Domain: Basic understanding of building terminology 
●​ Mathematics: Area calculations, cost analysis, resource planning 
Hardware Requirements 
●​ Processor: Intel i5/AMD Ryzen 5 or better 
●​ RAM: Minimum 8GB (16GB recommended for Ollama) 
●​ Storage: 10GB free space (for Granite model) 
●​ Internet: Required for initial setup only
